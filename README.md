# 漢字 Anki Deck Templates

Card templates for a **kanji recognition** Anki deck — Japanese → Spanish/English.

👉 **[Download the deck on AnkiWeb](https://ankiweb.net/shared/info/829123949)**

## Files

| File | Purpose |
|------|---------|
| `front.html` | Front template — shows meaning + hint + picture |
| `back.html` | Back template — reveals the kanji expression |
| `style.css` | Shared styles for both sides |

## Fields

| Field | Description |
|-------|-------------|
| `Expression` | Target kanji (character or compound) |
| `Meaning (spanish)` | Spanish translation |
| `Meaning (english)` | English translation |
| `Hint` | Sample vocabulary using the kanji |
| `Picture` | Optional image |

## Setup

1. In Anki, go to **Manage Note Types** → pick your note type → **Cards**
2. Paste `front.html` into the **Front Template** box
3. Paste `back.html` into the **Back Template** box
4. Paste `style.css` into the **Styling** box

Works on **Anki Desktop** (macOS / Windows / Linux) and **AnkiDroid**.
